About the Project

Campus Connect is a student-focused website concept designed to help university students organize their class schedules, track assignment deadlines, and stay updated with important campus announcements.

Key Features

📅 Class Schedules

Keep class times and daily activities organized in one place.

📝 Assignment Tracking

Keep track of assignment deadlines and upcoming coursework.

📢 Campus Updates

Make important campus announcements easier to find.

Technologies Used

HTML, CSS, and JavaScript
